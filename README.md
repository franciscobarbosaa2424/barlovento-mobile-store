# Barlovento Mobile Store

Final project for my Programmer Analyst degree (2024): a desktop application for managing a mobile phone store and its repair services, built with C# Windows Forms and SQL Server.

## Technologies

- C# Windows Forms
- SQL Server

## Getting Started

1. Import the database script from the `BBDD` folder into SQL Server.
2. Open the solution (`.sln`) in Visual Studio.
3. Open the connection class in the `Persistencia` folder and update the connection string with your SQL Server instance and the name of the imported database.
4. Build and run the application from Visual Studio.
